CANTEEN POS - WEB EDITION (PUBLISH COPY)
========================================

This folder is the online-ready copy of the showcase microsite.
The original offline edition is kept separately in Desktop\Canteen POS\Microsite.

WHAT IS HERE
  index.html          The entire site (CSS and JavaScript are inline)
  assets\             Six application screenshots and the favicon
  docs\               Source-code appendix (HTML), rationale (DOCX), figure PNGs
  WEB-CHANGES.txt     Exact differences from the offline edition

HOSTING
  Upload the CONTENTS of this folder to any static web host.
  index.html must be at the site root, with assets\ and docs\ beside it.
  No PHP, database, npm or build step is needed on the host.

BEFORE PUBLIC LAUNCH
  1. Remove <meta name="robots" content="noindex"> from index.html.
  2. Replace the "Project team" footer link with an official contact address if needed.
  3. Confirm the eight team names may be published, and add real roles if required.

TESTING
  Double-click index.html, or serve this folder with any static server.
  All links are relative, so this copy also works offline from a USB drive.
