Appendix A — System Architecture and Deployment

A.1 Runtime architecture

   Browser / WebView (cashier POS screen or admin page)
                    |  HTTP
                    v
   +----------------------------------------+
   | PHP 8.3 built-in server   :8000        |
   | app/public/*.php  ->  API endpoints    |
   +----------------------------------------+
       |  PDO / SQL                  ^
       v                             | query results
   +----------------------------------------+
   | MariaDB 11.4            :3399          |
   | database: canteen_pos                  |
   +----------------------------------------+
       ^                             ^
       | started / stopped by        | data files
       |                             |
   +----------------------------------------+
   | CanteenPOS.exe (portable launcher)      |
   | - bundles PHP + MariaDB runtime         |
   | - probes free ports (8000/3399)         |
   | - data home: %LOCALAPPDATA%\Canteen POS |
   |   config.env, data/, uploads/, backups/ |
   +----------------------------------------+

Every page calls api/secure_session.php before starting a session, then api/config.php for database access and shared helpers. All screen data is read from the APIs; the browser never connects to MariaDB directly.
